# Реальные аудиофайлы и выбор источников — этап 2

Дата: 2026-10-04. Спецификация: [sound.md](../specs/sound.md).
Ветка `codex/sound-files` основана на `codex/sound` (`0741d13`): первый этап ещё в открытом PR #6.
Черновик [PR #7](https://github.com/dmtrml/archipelago/pull/7) — отдельный зависимый PR;
после слияния первого его базу можно перенести на `main`.

Подготовлен комплект записей и индивидуальный выбор источника. После прослушивания владелец
предпочёл синтезированные эффекты, сохранив записи музыки и природы: это новый набор по умолчанию.
Каждый звук можно переключить отдельно. Качество сигналов, лицензии и воспроизведение проверены
технически; оценку на слух делает владелец.

## Выбор для игры

В `/?sound` у каждого звука есть «В игре — Синтез / Запись», основная кнопка выбранного образца
и две кнопки сравнения. Сравнение не меняет сохранённый выбор и заменяет предыдущий образец,
включая запись, которая ещё декодируется. Фоновые сцены и природа продолжают звучать.
Источник текущей музыки и непрерывной природы меняется плавно, сохраняя сцену и погоду.
Отдельные эффекты используют выбранный источник при следующем игровом событии.

Настройки источников сохраняются в `archipelago.audio.v1` вместе с громкостями. Старые настройки
сохраняют громкости и получают новые источники по умолчанию; неизвестные или повреждённые значения
игнорируются. `epilogue` и `music.epilogue` имеют общий выбор. Кнопка возврата исходного набора
меняет только источники. Панель звука в игре содержит ссылку на витрину.

## Комплект

43 MP3 покрывают все 42 CueId: два варианта клика и два островных трека,
а `epilogue` и `music.epilogue` используют одну короткую запись.

- Эффекты — 34 файла, моно, 44,1 кГц, 96 кбит/с: **323 447 байт**, самый большой — 36 720 байт.
  Монеты, бумага, деревянные удары и звон взяты из CC0-наборов Kenney; короткие музыкальные
  фразы — из Ukulele Forest. Афера продолжает звучать как обычная покупка.
- Природа — три петли по 30 с с круговым кроссфейдом 5 с; отдельные чайки и далёкий гром.
  Полевая запись моря: tonyg74, пальмового ветра с насекомыми: Felix Blume,
  дождь: Ylmir, чайки: svenne2000, гром: TRP. Все CC0.
- Музыка — 128 кбит/с, 44,1 кГц, стерео: Happy Ukelele Island Surfing Theme (135,81 с, 99 BPM
  в метаданных); Sicilian sun (авторская петля повторена 8 раз, 91,86 с);
  Apple Cider для свободы (199,84 с); вступление + окончание Ukulele Forest для эпилога (6,71 с).
  Sicilian sun — CC-BY 3.0, остальные — CC0. Оценки темпа Sicilian sun (~83) и Apple Cider (~99)
  получены анализом сигнала, а не авторскими метаданными. Темп и высота музыки не изменены.
  Две длинные темы также содержат цифровые инструменты по описанию источников; выбор вкуса остаётся владельцу.

Все файлы вместе — **8 429 536 байт**. Исходные архивы, полные полевые записи и альтернативные
кандидаты остаются в игнорируемом кэше. [CREDITS.md](../../CREDITS.md) перечисляет файл → автор →
источник → лицензия и изменения; его копия поставляется вместе с приложением, ссылка доступна в панели звука.

## Сигнал и воспроизведение

[Отчёт по всем MP3](sound-files/assets-report.json) проверяет кодек, частоту, каналы, размер,
длительность, SHA-256, RMS и пик уже после обратного декодирования MP3.
Максимальный пик — **−3,912 dBFS**, клиппинга нет. Эффекты нормализованы к −22 dBFS RMS
с ограничением сырого пика −4 dBFS; тихие отрицательные/далёкие звуки — ниже.
Музыка после MP3 имеет RMS около −26,44 dBFS, природа — −27…−28 dBFS;
обычные настройки шин дополнительно делают музыку заметно тише эффектов.
Для петель скачок на стыке ниже 99-го процентиля внутренних соседних разностей;
это проверка непрерывности сигнала, не оценка петли на слух.

При выбранном синтезе записи этого звука не загружаются. Игровые эффекты срабатывают сразу:
если выбрана запись, а декодирование ещё не закончено, используется синтез.
Выбранная записанная природа плавно переходит с начального синтеза на загруженную запись. Музыкальные сцены и образцы
витрины используют `HTMLAudioElement`, целые треки не декодируются через Web Audio.
До первого жеста нет AudioContext, загрузок аудио или предупреждений автоплея.
Скрытие вкладки приостанавливает и контекст, и сам поток; возвращение продолжает запись с того же места.

Витрина показывает сохранённый источник, ждёт декодирования выбранных записей эффектов,
воспроизводит музыку целиком, даёт отдельные кнопки вариантов и короткий образец петли природы. При повреждении записи
звучит синтез; журнал указывает реальный источник, включая событие эпилога.

## Воспроизведение проверок

- `npm run typecheck`, `npm test` (140 тестов), `npm run build` и `git diff --check` проходят.
- [Playwright / headless Edge: 37 сценариев](sound-files/results.json), все 42 образца используют
  сохранённый выбор; отдельно все 42 записи реально воспроизводятся из файлов;
  [журнал](sound-files/audio-log.json). Ошибки выполнения/консоли/автоплея — 0.
  Проверены набор по умолчанию, смешанные источники при покупке, сохранение после reload,
  выбор при недоступном Web Audio/хранилище и смена музыки/моря в обе стороны без сброса шторма.
  Проверены второй музыкальный вариант, отсутствие декодирования музыки через fetch,
  ровно 30 с в браузерном декодере петель и резервный синтез при повреждённых эффекте и треке.
- Скрытие вкладки проверяется управляемым `visibilitychange`: настоящий контекст suspend/resume
  и настоящие media-элементы pause/play, без продвижения времени скрытого трека.
- Настройки проверены в интерфейсе и localStorage, затем реальная громкость всех шин при активном
  источнике. [Отдельный разбор](sound-files/idle-gain-summary.json) подтверждает: getter неактивной
  AudioParam может хранить старое вычисленное значение, хотя расписание и физический выход верны.
- Голосов не больше 16; сброс, шторм, свобода, соседи, мечта, эпилог и отсутствие Web Audio/хранилища проходят.

JS звукового модуля, витрины и привязки — около **14,42 КБ gzip**, отдельные стили — 1,97 КБ.
Рост игрового JavaScript относительно базы до звука — около **12,2 КБ gzip**, в пределах ~20 КБ.
Прежнее предупреждение о большом 3D-чанке остаётся.

Четыре ключевых JPEG второго этапа, каждый меньше 150 КБ. Скрипт также создаёт два снимка
шапки в кэше; неизменённая геометрия шапки уже зафиксирована в первом этапе.

Обычные команды: `npm run typecheck`, `npm test`, `npm run build`, `git diff --check`.
Зависимости приложения не менялись, движок и 3D-сцена не менялись.
Для браузерного сценария нужен свежезапущенный Vite без редактирования исходников во время прогона;
Playwright и Microsoft Edge, как описано в [приёмке первого этапа](sound.md).

```powershell
npm run dev -w @arch/web -- --host 127.0.0.1 --port 5182 --strictPort
```

В другом терминале:

```powershell
node scripts/check-sound.mjs --url http://127.0.0.1:5182 --fixture node_modules/.cache/sound-qa/fixtures.json --output node_modules/.cache/sound-files/results
node --import tsx scripts/check-sound-music.mjs node_modules/.cache/sound-files/music-checks.json
node --import tsx scripts/check-sound-files.mjs
```

Фикстуры создаются скриптом `scripts/fixtures/sound.ts` из первого этапа.
[11 проверок музыкального расписания](sound-files/music-checks.json) и
[28 проверок источников/хранилища/ошибок/потоков](sound-files/integration-checks.json) используют настоящие
модули с управляемыми таймерами и подменами аудио; они не выдают себя за браузерное прослушивание.
Проверены быстрый A/B без наложения, отмена позднего образца, сохранение старых громкостей,
очистка неверных настроек и отсутствие повторных перезапусков резервного синтеза при ошибке файла.

Для сборки аудио нужны Python с numpy, FFmpeg и FFprobe в PATH:

```powershell
python scripts/build-sound-assets.py --fetch
python scripts/build-sound-assets.py --check
```

Исходники, лицензии, SHA-256 и рецепты монтажа заданы в `scripts/audio-sources.json`.
`--fetch` сверяет архивы и безопасно распаковывает их; `--check` проверяет готовые MP3.
Скрипт также обновляет обе копии `CREDITS.md`; новые зависимости игры не нужны.
