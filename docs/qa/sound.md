# Приёмка: звук и музыка, этап 1

Дата: 2026-10-04. Спецификация: [sound.md](../specs/sound.md).
Ветка `codex/sound`, база `main` — `84a57a6`; перенос соседей (PR #4) уже включён.

Игра получила 42 синтезированных звука, три музыкальные сцены, природу с плавным штормом,
панель громкости и отдельную ленивую витрину `/?sound`. Аудиофайлов и новых зависимостей нет.
`packages/engine`, `apps/web/src/scene` и lockfile не изменены.

## Проверки

- `npm run typecheck` — проходит для движка и веба.
- `npm test` — 140 тестов в 5 файлах проходят. На этом Windows-хосте Vitest запускается вне
  песочницы: её виртуальный TEMP вызывает ENOENT до выполнения тестов.
- `npm run build` и `git diff --check` — проходят. Прежнее предупреждение о большом 3D-чанке осталось.
- Playwright / headless Microsoft Edge — [32 сценария](sound/results.json), ошибок выполнения,
  ошибок консоли и предупреждений автоплея нет.
- До первого жеста, включая загрузку сохранения, созданных AudioContext — 0; `window.__audioLog`
  отсутствует. После старта игры — `ui.click`, островная музыка, море и ветер.
- Все успешные действия имеют нужные звуки и порядок; покупка аферы звучит как обычный актив,
  отказ даёт `ui.error`. Для исчерпывающего покрытия действий тест вызывает публичный `store.act`;
  новая игра и следующая неделя нажимаются через интерфейс.
- В недельном отчёте количество монет совпадает с количеством положительных/отрицательных сумм;
  шаг высоты растёт 0…7, звук и добавление суммы отличаются менее чем на 40 мс.
- Шторм включает дождь и усиленный ветер и возвращается к обычной природе через 7 секунд.
  Свобода переключает музыку на `free`; запуск шхуны звучит перед открытием эпилога,
  короткая тема эпилога затем возвращает `free`. Событий за неделю не больше двух.
- Проверены свобода соседа, крах аферы, уровни свободы и промежуточные этапы мечты.
- Выключение сразу устанавливает master gain в 0; ползунки меняют свои шины, настройки переживают
  перезагрузку. Управляемый `visibilitychange` с настоящим `AudioContext.suspend/resume` проверяет
  скрытие/возврат вкладки и быстрый возврат; системное переключение окон headless-тест не имитирует.
- Быстрое отключение/включение природы и clear→storm→clear→storm сохраняет нужные слои.
  При перегрузке голоса никогда не превышают 16. Сброс очищает голоса и отложенные звуки.
- Без debug-флага глобального журнала нет. При недоступном Web Audio или запрещённом localStorage
  игра запускается и переключает недели без ошибок.
- Витрина содержит все 42 образца, каждый добавляет запись в журнал; каскад ×8 даёт шаги 0…7.
  [Полный вывод `window.__audioLog`](sound/audio-log.json) сохранён текстом, без дампов аудио.
- Панель проверена на 1366×768 и 390×844 с коротким и 24-символьным названием: четыре аватара,
  динамик и «↺» видимы, пересечений и горизонтального overflow нет. Escape возвращает фокус,
  клик снаружи закрывает панель. На узком телефоне второстепенная подпись скрывается, чтобы
  текущая неделя оставалась читаемой.
- OfflineAudioContext в Edge: 39 конечных рецептов × 2 варианта и ещё 10 повторов музыки.
  Нет пустых, неконечных, клиппированных или выходящих за длительность образцов.
  Максимальный сырой пик — 0,275 (−11,21 dBFS), RMS — 0,009–0,032; конец эпилога — 7,425 с при длительности 7,5 с.
  Проверена очистка 2404 узлов, естественное завершение и повторный `stop()`.
- [11 проверок музыкального расписания](sound/music-checks.json) на настоящем модуле с управляемыми
  таймерами и подменами Web Audio: чередование треков, паузы 20–60 с, кроссфейд 2,5 с,
  приглушение −9 дБ на 3 с, возврат из эпилога, потоковая музыка без декодирования,
  лимит голосов, очистка и переход к синтезу при ошибке файла.
- [Отдельная браузерная проверка сцен](sound/scene-checks.json) на обоих размерах подтверждает,
  что выделенная кнопка витрины меняется с «Эпилог» на «Свобода» после окончания темы.

## Повторение проверки

Нужны зависимости проекта, Playwright и браузер. На Windows скрипт использует Microsoft Edge;
другой канал задаётся `--channel`. Если Playwright установлен вне проекта, задайте
`PLAYWRIGHT_MODULE` путём к его модулю.

Для приёмки используйте **свежезапущенный Vite**, не редактируя исходники во время прогона:
после HMR импорт `/src/store.ts` тестом может отличаться от экземпляра, загруженного приложением.

В отдельном терминале:

```powershell
npm run dev -w @arch/web -- --host 127.0.0.1 --port 5182 --strictPort
```

Затем:

```powershell
New-Item -ItemType Directory -Path node_modules/.cache/sound-qa -Force | Out-Null
& ./node_modules/.bin/tsx.cmd scripts/fixtures/sound.ts node_modules/.cache/sound-qa/fixtures.json
node scripts/check-sound.mjs --url http://127.0.0.1:5182 --fixture node_modules/.cache/sound-qa/fixtures.json --output node_modules/.cache/sound-qa/results
node --import tsx scripts/check-sound-music.mjs
```

Фикстуры создаются исключительно через `createWorld` и `applyAction`, seed 1, недели 1–100.
JSON сохранений остаётся в игнорируемом каталоге; в Git — только скрипты, журнал и результаты.
Ожидания Playwright используют синхронные предикаты, чтобы проверка не завершалась на самом Promise.
